# 프로토콜

클라이언트와 서버가 주고받는 메시지입니다. 모두 WebSocket 텍스트입니다. 서버가 메시지를 어떻게 처리하는지는 [server/README.md](../server/README.md)에 있습니다.

- **클라이언트 → 서버**: `명령 인자…` 형태의 한 줄. 모르는 명령과 형식이 틀린 요청은 무시합니다.
- **서버 → 클라이언트**: JSON 객체. `t`가 종류입니다. 아래 표는 키만 적었습니다.
- 입장하기 전에는 `login`, `resume`, `join`만 받습니다.

## 클라이언트 → 서버

| 메시지 | 설명 |
|---|---|
| `login <아이디> <비밀번호>` | 로그인. 없는 아이디면 가입 |
| `resume <표>` | 로그인 때 받은 이어 들어오기 표로 비밀번호 없이 로그인. 틀리거나 만료되면 `auth` 의 `ok:false`, `resume:true` |
| `join <#rrggbb> <팔> <다리> <팔다리색> <닉네임>` | 캐릭터를 정하고 입장 |
| `in <비트마스크>` | 누른 방향키 (1=상, 2=하, 4=좌, 8=우) |
| `chat <내용>` | 전체 채팅 (최대 200자). 감정표현 문구와 정확히 같으면 `emote`로 처리 |
| `tv <명령>` | `play <영상 ID>`, `reel <릴스 코드>`, `pause`, `resume`, `seek <초>`, `stop`, `end <영상 ID>`, `share`(내 화면을 이 방의 화면에 띄우기 시작) |
| `board <켜기> <문구>` | 광고판 설정. `켜기`는 0 또는 1, 문구는 최대 30자이며 꺼 둘 때도 저장 |
| `light <항목> <값>` | 방 조명. 항목은 `room`(0, 1), `lamp`(0, 1), `level`(10~100) |
| `note <건반>` | 피아노 연주. 건반은 0~16 (C4부터 반음씩), 피아노 의자에 앉아 있어야 함 |
| `drop <번호> <개수>` / `eat <번호>` / `buy <번호>` | 아이템 버리기, 먹기, 매점에서 사기. 번호는 물고기(0~2), 드롭 아이템(3~4), 매점 물건(5~12) 순서. `drop`은 그 뒤의 농장 물건(13~42 = 13 + 물건 번호)도 받는다 |
| `jazz <명령>` | 레코드판이 있는 방(재즈바, 레코드 플레이어를 놓은 집)에서만. `add <영상 ID> <제목>`, `remove <영상 ID>`, `play <영상 ID>`, `next <세대>`, `stop`, `resume` |
| `dart <명령>` | 다트가 있는 방(재즈바, 다트판을 놓은 집)에서만. `new <2\|3>`, `join`, `leave`, `lock <단계 번호> <밀리초>` |
| `decor <명령>` | `buy <번호>`, `place <번호> <x> <y>`(집 안. 텃밭과 마당 꾸미기는 마을의 집 문 근처에도), `take <배치 번호>`, `buydye`, `dye <번호> <염색 값>`, `redye <염색 가구 칸> <염색 값>`, `placedyed <염색 가구 칸> <x> <y>`, `move <배치 번호> <x> <y>`, `turn <배치 번호>`(침대·깔개·텃밭은 90도씩, 그 밖의 가구는 좌우 뒤집기), `scale <배치 번호> <퍼센트>`(크기, 가구마다 `smin`~`smax`). 옮기기, 돌리기, 크기는 내 것, 집 가구, 동거인의 것만. 염색 값은 `rrggbb-명도(50~150)-채도(0~200)` |
| `floor <번호>` | 바닥재. 아직 없으면 사고(한 번만), 집 안이면 지금 집에 깐다. 0은 원래 바닥(무료). `floor dye <염색 값>`은 지금 집 바닥 염색(염료 1), `floor undye`는 원래 색 |
| `stats [연결 번호]` | 상태창. 비우면 나 |
| `visit <구역>` | 미니홈피 이동. 집 구역으로만, 문 안쪽에 선다 |
| `boardstyle <0\|1>` | 광고판 모양. 0 기본, 1 도트 |
| `use [door\|sit]` | E. `door`는 문만, `sit`은 앉기와 일어나기만, 없으면 문을 먼저 보고 앉기 |
| `lamp` | L. 손 닿는 스탠드를 켜고 끈다 |
| `buypet <번호>` | 펫 사기. 같은 펫은 한 번만, 첫 펫은 바로 데리고 다닌다 |
| `walkpet <번호\|-1>` | 가진 펫을 데리고 다니기(풀어놓은 펫이면 불러온다), `-1`이면 집에 두기 |
| `friend <명령>` | 친구. `ask <연결 번호>`, `name <이름>`, `yes <받은 신청 번호>`, `no <받은 신청 번호>`, `remove <친구 번호>`, `todo <친구 번호>`(그 친구의 할 일을 보고 바뀌면 계속 받음), `unwatch` |
| `guest <명령>` | 방명록. `look <구역>`(열거나 다른 집으로, 그 뒤로 새 글을 받음), `close`, `write <구역> <글>`(집만, 100자, 10초에 한 번), `del <글 번호>`(쓴 사람만) |
| `todo <명령>` | 할 일. `add <날짜> <글>`, `done <번호>`(다 했음을 바꿈), `del <번호>`, `edit <번호> <글>`, `date <번호> <날짜>`(다른 날로 옮김), `move <번호> <자리>`(그 일을 빼서 그 자리에 넣음: 같은 날 안에서는 그 자리에 있던 일의 위치로 감), `clear [날짜]`(그날, 없으면 모든 날의 다 한 일 지우기), `share <0|1>`(친구에게 공개), `today <날짜>`(이 화면의 오늘: 친구 목록이 그날 할 일을 셈). 날짜는 yyyymmdd, 글은 40자, 하루 30개·모두 200개까지 |
| `mate <명령>` | 동거인. `ask <연결 번호>`, `yes <연결 번호>`, `no <연결 번호>`, `remove <내 목록의 번호>` |
| `releasepet <번호>` / `callpet <번호>` | 지금 있는 집에 펫 풀어놓기 / 풀어놓은 펫 불러와 데리고 다니기 |
| `arcade <명령> <배치 번호> ...` | 오락기. `look`(창을 열어 구경, 구경꾼 수에 들어감), `unlook`, `join <0 1P|1 2P>`(가까이서만), `leave`, `start`(앉은 사람, 두 자리가 차면 슈팅·벽돌깨기는 함께, 지뢰찾기·체스는 대전), `score <점수> <1P 목숨> <끝났는지 0/1> [2P 목숨]`(판을 돌리는 화면만, 초당 1500점보다 빨리 오르거나 줄어든 점수는 버림, 60초 동안 안 오면 판 종료), `sync <판 JSON>`(판을 돌리는 화면의 중계, 12000자·출력 가능한 ASCII만, 틱마다 4번까지), `in <x> <쏘는지 0/1>`(함께 하는 2P 의 조작), `dig <칸>`(지뢰찾기), `move <출발 칸> <도착 칸> [q|r|b|n]`·`undo`·`hint`(체스, 칸은 0 이 a8 이고 63 이 h1, 무르기와 힌트는 컴퓨터와 둘 때만) |
| `expand <명령> <방향> …` | 집 확장. `open [통로 폭]`, `close`, `width <통로 폭>`(뚫어 둔 통로의 폭 바꾸기), `size <방 길이> <방 깊이>`(붙인 방의 크기. 길이는 뚫은 벽과 나란한 쪽 200~900, 깊이는 200~700). 방향 0 위, 1 아래, 2 왼쪽, 3 오른쪽. 넓힐 수 있는 집 안에서만 |
| `omok <명령>` | 오목판이 있는 방에서만. `sit`, `leave`(두는 중이면 기권), `put <칸 0~224>`, `again`, `watch`/`unwatch`(관전) |
| `trade <명령>` | `ask <상대>`, `yes <상대>`, `no <상대>`, `item <번호> <개수>`(번호는 `drop`과 같다), `gold <금액>`, `ready`, `cancel` |
| `pachi shoot` | 빠칭코 구슬 하나 (카지노 기계 의자에 앉아 있을 때만, 1골드, 초당 3.5개, 6개까지 연사) |
| `ext <집 구역> <벽 0~8> <지붕 0~8> <문 0~7> <장식 비트 0~63> [모양 0~8]` | 집 외관. 그 집 안이나 마을에서 그 집 문 앞에서만 |
| `fish` | 던지기, 낚아채기, 거두기 |
| `pet` / `feed` | 근처 고양이 쓰다듬기 / 물고기 주기 |
| `rtc <상대 연결 번호> <내용>` | 화면 공유의 연결 정보(WebRTC). 공유하는 사람과 같은 방에서 보는 사람 사이에서만 그대로 전한다 |
| `buyemote <번호>` | 상점의 감정표현 사기. 같은 것은 한 번만 |
| `focus <명령>` | 함께 집중. `list`(들어갈 수 있는 모임), `open <분>`(모임 만들기), `join <모임 번호>`, `leave`. 방장만: `invite`(모집 알림 다시 보내기), `mins <분>`, `start [분]`, `stop`(일찍 끝내기). 분은 1~180 |
| `farm <명령>` | 농장 안에서만(`eat`은 어디서나). `buy <작물> [개수]`(씨앗 가게 앞), `sell <물건> [개수]`(출하 상자 앞), `egg`(닭장 앞), `milk`(젖소 앞), `plant <칸> <작물>`, `water <칸>`, `harvest <칸>`, `dig <칸>`(내 작물 뽑기), `eat <요리의 물건 번호>` |
| `garden <명령>` | 집과 마당의 텃밭. `plant <배치 번호> <작물>`, `water <배치 번호>`, `harvest <배치 번호>`, `dig <배치 번호>` |
| `cook <명령>` | 조리대 앞에서. `start <요리법>`(재료를 확인하고 `cook`으로 답함), `done <점수 0~100>`(과정 하나에 1.5초가 지나지 않았으면 무시), `cancel` |

## 서버 → 클라이언트

| 메시지 | 설명 |
|---|---|
| `{"t":"auth","ok","new","id","nick","rt","h","arms","legs","limb"}` | 로그인 성공 (실패 시 `ok:false`, `m`). `rt` 는 30일 동안 쓰는 이어 들어오기 표 `<아이디 16진수>.<만료 초>.<HMAC-SHA256>` |
| `{"t":"kick","m"}` | 다른 곳에서 로그인하여 끊김 |
| `{"t":"welcome","id","w","h","speed","tick","catMs","c","l","s","g","hp","maxHp","pachiCost"}` | 입장 승인 (`c`: 종류별 물고기 수, `l`: 드롭 아이템 수) |
| `{"t":"map",...}` | 입장 시 1회. 강둑, `zones`, `buildings`, `solids`, `furn`, `seats`, `trees`, `lamps` |
| `{"t":"zone","z","x","y"}` | 구역 이동 |
| `{"t":"time","p","len"}` | 낮밤 시계. 낮은 `[0, len)`, 밤은 `[len, 2*len)` |
| `{"t":"state","k","on","p":[{"id","x","y","c","n"}]}` | 매 틱, 같은 구역의 플레이어. `k` 는 틱 번호. 필요할 때만 `d`(누르고 있는 방향 비트, 앉거나 낚시 중이 아닐 때), `a`(외형 = 팔 + 다리×3 + 색×9), `s`(자리 번호+1), `f`(1 대기, 2 입질), `bx`, `by`, `pt`(데리고 다니는 펫 번호), `fc`(집중 타이머가 도는 중이면 1) 추가 |
| `{"t":"cats","p":[[x,y]]}` | 같은 구역의 고양이 위치 (`catMs`마다). 집에 풀어놓은 펫은 `[x,y,펫 번호]`, 자는 동물은 `[x,y,펫 번호(펫이 아니면 -1),1]` |
| `{"t":"arcade","id","g","s","vs","co","wc","seed","el","sc","lv","dn","w","why","p","n"[,...]}` | 오락기 한 대의 판. `g` 0 슈팅 1 벽돌깨기 2 지뢰찾기 3 체스, `s` 0 기다림 1 하는 중 2 끝, `vs` 둘이 시작, `co` 슈팅·벽돌깨기를 함께, `wc` 구경꾼 수, `p`/`n`은 1P·2P의 연결 번호와 이름, `w`는 이긴 쪽(체스는 0 백 1 흑, 2 비김, -1 승부 없음). 지뢰찾기는 `size`, `mc`, `st`(혼자 하는 단계), `nx`(깨고 다음 단계로 넘어가는 중), `b`(`.` 덮임, `0`~`8`, `a`/`b` 1P·2P가 찾은 지뢰, `x` 터진 지뢰, `*` 드러난 지뢰), `tn` 차례, `tl` 남은 초, `f` 찾은 수. 체스는 `cb`(64칸, 백은 대문자), `ct` 둘 차례, `ck` 체크 받은 킹의 칸(-1 없음), `lm` 마지막 수, `ai` 컴퓨터 단계, `as` 컴퓨터의 색, `th` 컴퓨터가 생각 중, `hn` 힌트, `np` 둔 수, `tl` 사람끼리 둘 때 남은 초, 하는 중에는 `cm`(둘 수 있는 수 `출발.도착`, 프로모션은 뒤에 `p`)와 `hg`(지켜 주는 말 없이 공격받는 칸). 오락기를 치우면 `{"t":"arcade","id","off":true}` |
| `{"t":"asy","id","d"}` | 함께 하는 2P 와 구경꾼에게 판을 돌리는 화면의 판(`d` 는 JSON 문자열) |
| `{"t":"ain","id","x","f"}` | 1P 화면에 함께 하는 2P 의 로켓·라켓 자리와 쏘는지 |
| `{"t":"room","z","zone","solids","furn"}` | 누가 집을 넓히거나 막았을 때 모두에게. 그 구역의 모습(`floors`, `x0`, `y0`, `base`, `open` = `[방향, 통로 가운데, 통로 폭, 방 길이, 방 깊이]` 목록, `omax` = 방향마다 낼 수 있는 가장 넓은 통로, `osize` = 방 크기의 범위), 고정 충돌 영역, 고정 가구(뚫은 벽에서 뗀 장식은 빠짐) |
| `{"t":"omok","b","p","w","turn","win","play","last","left","why"}` | 오목 상태. `w`는 관전자 이름. `b`는 225칸(0 빈칸, 1 흑, 2 백), `p`는 `[흑, 백]`의 `[id, 이름]`. 판을 치우면 `{"t":"omok","off":true}` |
| `{"t":"cat","i","act","id","n"}` | 고양이 상호작용. `feed`면 `k`, `c` 추가 |
| `{"t":"catch","id","n","k","c"}` | 물고기를 낚음 |
| `{"t":"chat","id","n","c","m"}` | 채팅 |
| `{"t":"light","on","lamp","lv"}` | 방 조명 상태. 조명이 있는 방에 들어올 때와 바뀔 때 |
| `{"t":"emote","id","n","e"}` | 같은 구역의 감정표현. `e`는 박수, 꿀맛, 행복, 엉엉, 기쁨 순서의 번호 |
| `{"t":"tv","v","reel","pos","paused"}` | 방의 TV 상태. 들어올 때와 바뀔 때. `v`가 비어 있으면 꺼짐. 화면 공유 중이면 `v`가 `@share`이고 `share`(공유하는 사람의 연결 번호), `sn`(이름)이 붙는다 |
| `{"t":"jazz","gen","i","pos","stop","list"}` | 레코드판 상태. 레코드판이 있는 방에 들어올 때와 바뀔 때. `list`는 `[영상 ID, 제목]` 목록, `i`는 현재 곡, `stop`은 정지 중. 집의 레코드 플레이어를 치우면 `{"t":"jazz","off":true}` |
| `{"t":"dart","st","size","turn","round","rounds","phase","seq","age","off","lx","players","hits","win"}` | 다트 상태. 재즈바에 들어올 때와 바뀔 때. `st`는 0 없음, 1 대기, 2 경기, 3 결과. `phase`는 0 가로, 1 세로, 2 쉬는 중 |

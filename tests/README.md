# 테스트

서버를 빌드해 임시 포트와 임시 데이터 폴더로 띄운 뒤, 프로토콜 봇(`lib.mjs`의 `Bot`)과 실제 Chrome(Playwright)으로 검사합니다. Chrome이 설치되어 있어야 합니다.

```bash
cd tests
npm install
npm test                  # 전체
node run.mjs housing ui   # 일부만
```

- 스위트는 기본 6개씩 동시에 실행되고, `TEST_JOBS`로 개수를 바꿉니다.
- 시간이 걸리는 규칙은 환경변수로 줄여서 검사합니다 (`MMO_FARM_SPEED`, `MMO_FOCUS_MINUTE_SEC` 등, [server/README.md](../server/README.md)의 설정 표).
- PBKDF2 구현은 Node의 `crypto` 결과와 비교합니다 (`crypto_check.cpp`).
- 화면 확인용 스크린샷은 `tests/.screenshots/`에 저장됩니다.
